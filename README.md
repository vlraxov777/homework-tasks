## 🛠 Инструкция по запуску проектов (Задание 1 и 2):

### 1. Консольный генератор паролей
Программа написана на чистом Python с использованием встроенных модулей и цветного вывода в консоль.
* **Как запустить:**
  ```bash
  cd task-1
  python3 task-1.py
  ```

### 2. Телеграм-бот (aiogram)
Асинхронный бот, обрабатывающие команды `/start` и `/swaga`.
* **Ссылка на бота в Telegram:** [@dynasty_swaga_bot](@dynasty_swaga_bot)
* **Как запустить:**
  *Примечание: Перед запуском рекомендуется включить VPN на устройстве для стабильного соединения с серверами Telegram.*
  ```bash
  cd task-2
  pip3 install aiogram
  python3 task-2.py
  ```

---

## 🐳 Как запустить бота через Docker (Задание 3):

Проект упакован в изолированный Docker-контейнер на базе легковесного образа `python:3.11-slim`. Это позволяет развернуть бота на любом удаленном VPS-сервере в одну команду.

* **Команда для сборки Docker-образа:**
  ```bash
  cd task-3
  docker build -t my-tg-bot .
  ```
* **Команда для запуска бота в фоновом контейнере:**
  ```bash
  docker run -d --name bot-container my-tg-bot
  ```

## 🔮 Мой следующий проект: Дедлайн-бот с базой данных SQLite

В процессе выполнения этой практики у меня появилась идея создать полезный инструмент для студентов - планировщик задач и дедлайнов. Мне очень захотелось совместить свои знания SQL и Python, чтобы реализовать их вместе в одном общем проекте. 

Из-за дедлайна по домашней работе и нехватки опыта я не успеваю полностью написать код прямо сейчас, но я продумал логику будущего бота . Так как у меня пока ещё не очень много опыта, я буду продолжать активно изучать SQL и Python, потихоньку улучшать свои навыки и шаг за шагом писать этого бота. 

**💡 Суть идеи и логика работы:**
Бот помогает студентам не просыпать дедлайны по учебе. Ученик сам вводит свои задачи, а Python берет эти данные и записывает в таблицы SQL. Бот работает как интерактивный блокнот и сам присылает напоминания в чат за 2 дня и за 1 день до конца срока.

**🗄 Структура хранения данных:**
Вся информация записывается в базу данных SQLite:
1. **ID задачи** — уникальный порядковый номер (идентификатор для удобного поиска или удаления конкретной задачи).
2. **ID пользователя** — уникальный номер студента в Телеграме (чтобы каждый видел только свои задачи).
3. **Предмет** — название учебной дисциплины.
4. **Задача** — описание того, что конкретно нужно сделать по предмету.
5. **Дедлайн** — дата и время, до которых нужно сдать работу.

**PS:** Я отлично понимаю, что в таком боте нет какого-то нового смысла, ведь на любом телефоне и так есть обычные напоминалки. Но мне просто хочется самому попробовать сделать такого бота с нуля, покодить работу с базой данных своими руками и посмотреть, как это всё вообще работает вживую на практике)
