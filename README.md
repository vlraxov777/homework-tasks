# Практическая работа для поступления в комитет ИК

В репозитории представлены решения трёх практических заданий.

## 📁 Структура проекта:
* **task-1/** — Консольный генератор безопасных паролей.
* **task-2/** — Телеграм-бот на aiogram, выдающий случайные строки из трека «ДИНАСТИЯ».
* **task-3/** — Телеграм-бот, подготовленный для упаковки в Docker-контейнер.

---

## 🛠 Инструкция по запуску проектов (Задание 1 и 2):

### 1. Консольный генератор паролей
Программа написана на чистом Python с использованием встроенных модулей и цветного вывода в консоль.
* **Как запустить:**
  ```bash
  cd task-1
  python3 task-1.py
  ```

### 2. Телеграм-бот (aiogram)
Асинхронный бот, обрабатывающий команды `/start` и `/swaga`.
* **Как запустить:**
  *Примечание: Перед запуском рекомендуется включить VPN на хост-машине для стабильного соединения с серверами Telegram.*
  ```bash
  cd task-2
  pip3 install aiogram
  python3 task-2.py
  ```

---

## 🐳 Как запустить бота через Docker (Задание 3):

Проект упакован в изолированный Docker-контейнер на базе легковесного образа `python:3.11-slim`. Это позволяет развернуть бота на любом удаленном VPS-сервере в одну команду.

* **Команда для сборки Docker-образа:**
  ```bash
  cd task-3
  docker build -t my-tg-bot .
  ```
* **Команда для запуска бота в фоновом контейнере:**
  ```bash
  docker run -d --name bot-container my-tg-bot
  ```
